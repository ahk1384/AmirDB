# AmirDB 🚀

**AmirDB** is a student-built database project that mixes **Java**, **C++**, **Python**, and **Rust** ideas into one fun learning project. It looks like a mini database / DBMS-style system with a **server**, **client**, **query parser**, **execution engine**, and **indexing** parts.

> A cool project made by Amir for learning databases, programming, and system design 💡

---

## ✨ What this project is about

AmirDB is focused on building a database system from scratch or at least a big part of it. It includes things like:

- a **console UI** for interactive use
- a **server/client** structure
- a **query parser**
- an **execution engine**
- **indexes** like BST-based indexing
- support for **student records** and storage logic

## ▶️ How to run

If you already have the runnable files:

### Run server
```bash
java -jar server-1.0.jar
```

### Run client
```bash
java -jar client-1.0.jar
```

If the server has a password, enter it when asked.
