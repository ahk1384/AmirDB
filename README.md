# AmirDB 🚀

**AmirDB** is a student-built database project made for learning and practicing **data structures**, **networking**, and **object-oriented programming** in a real-world style.

It uses a **client-server architecture** and supports **socket communication between two devices**, so the client and server can connect and exchange data over the network 🌐

## ✨ Why AmirDB is cool

- 🧠 Built using **data structures** for better data handling
- 🔌 Supports **socket communication** between two devices
- 🖥️ Uses a **client-server** design
- ☕ Mainly written in **Java**
- 🎨 Includes a **console-based UI**
- 📚 Great for learning **database concepts**, **network programming**, and **software design**

## 🌟 Features

- Run a database server
- Connect a client to the server
- Send and receive data through sockets
- Work with indexed data structures
- Simple and beginner-friendly interface

## 🛠️ Tech Stack

- **Java** — main language
- **C++** — extra support parts
- **Python** — helper / side tools
- **Rust** — experimental/template code

## ▶️ How to Run

### Server
Run the server jar file:

```bash
java -jar server-1.0.jar
```

If needed, set the server password.

### Client
Run the client jar file:

```bash
java -jar client-1.0.jar
```

If the server has a password, enter it when asked.
